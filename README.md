# جزایر — طلوع تمدن | ISLANDS: Rise of Civilization

یک بازی مرورگری سه‌بعدی ایزومتریک با رابط فارسی و راست‌به‌چپ، دو جایگاه حساب در یک جهان مشترک، جزیره‌های مستقل، جمع‌آوری منابع، ساخت‌وساز، چت زنده و ذخیره‌سازی پایدار. پروژه به‌صورت PWA آماده نصب روی گوشی است.

## نیازمندی‌ها

- Node.js نسخه 22 یا جدیدتر (برای ماژول پایگاه‌داده داخلی `node:sqlite`)
- npm
- برای اجرای عمومی: یک هاست Node.js با دیسک پایدار؛ برای دسترسی هم‌زمان دو بازیکن، هر دو باید به یک آدرس سرور وصل شوند.

## اجرای محلی

```bash
npm install
npm run build
npm start
```

سپس در مرورگر به `http://localhost:3000` بروید. برای توسعه با Vite:

```bash
npm run dev
```

در حالت توسعه، Vite روی پورت 5173 و سرور API/WebSocket روی پورت 3000 اجرا می‌شود؛ پروکسی API و WebSocket در Vite از پیش تنظیم شده است.

## ساخت دو حساب

1. نفر اول وارد صفحه شود و از زبانه «ساخت حساب» نام کاربری، نام شخصیت و گذرواژه حداقل ۸ نویسه‌ای بسازد.
2. نفر دوم با مرورگر یا دستگاه دیگر به همان آدرس سرور برود و حساب دوم را بسازد.
3. جهان فقط دو حساب می‌پذیرد. محدودیت در سرور و در تراکنش SQLite اعمال می‌شود؛ حساب سوم رد خواهد شد.
4. هر حساب جزیره و موجودی جداگانه دارد. موقعیت بازیکن، ساختمان‌ها، منابع، جمعیت و پیام‌های اخیر در پایگاه‌داده ذخیره می‌شوند.

## کنترل‌ها

- روی زمین جزیره ضربه بزنید یا کلیک کنید تا شخصیت به آن نقطه برود.
- از جوی‌استیک پایین صفحه برای حرکت لمسی استفاده کنید.
- «برداشت» نزدیک‌ترین منبع را جمع می‌کند؛ ابتدا به درخت یا سنگ نزدیک شوید.
- «ساخت‌وساز» را باز کنید، ساختمان را انتخاب کنید و روی محل مناسب جزیره بزنید.
- کیف، نقشه، گفت‌وگو و منوی تنظیمات از نوارهای صفحه در دسترس‌اند.

## نصب روی گوشی (PWA)

سایت باید از طریق HTTPS (یا localhost) باز شود. در Chrome اندروید، منوی سه‌نقطه را باز کنید و «Install app» یا «Add to Home screen» را بزنید. در مرورگرهای سازگار دیگر از گزینه نصب/افزودن به صفحه اصلی استفاده کنید. فایل manifest، آیکون‌ها و service worker در پروژه قرار دارند. پوسته و فایل‌های بازدیدشده برای دسترسی آفلاین cache می‌شوند؛ ورود، ذخیره جهان و چندنفره برای کارکردن به اینترنت و سرور نیاز دارند.

## تنظیمات سرور و استقرار

متغیرهای محیطی:

| متغیر | کاربرد | پیش‌فرض |
|---|---|---|
| `PORT` | پورت HTTP | `3000` |
| `SESSION_SECRET` | کلید امضای نشست | مقدار توسعه؛ در استقرار حتماً تغییر کند |
| `DB_PATH` | مسیر فایل SQLite | `./world.sqlite` |

نمونه:

```bash
SESSION_SECRET="یک-رشته-تصادفی-طولانی" DB_PATH="/var/data/world.sqlite" PORT=3000 npm start
```

برای استقرار، مخزن را روی یک سرویس Node.js قرار دهید، دستور build را اجرا کنید و start را به `npm start` تنظیم کنید. دیسک پایدار را به مسیر `DB_PATH` متصل کنید. اگر سرویس خواب/ری‌استارت شود، فایل SQLite روی دیسک پایدار باقی می‌ماند. از هاست‌هایی که فایل‌سیستم موقت دارند برای جهان دائمی استفاده نکنید. TLS/HTTPS را از طریق هاست یا reverse proxy فعال کنید؛ WebSocket نیز خودکار از `wss` استفاده می‌کند.

## پشتیبان‌گیری

سرور را متوقف کنید و فایل `world.sqlite` (و فایل‌های `world.sqlite-wal` و `world.sqlite-shm` در صورت وجود) را کپی کنید. برای بازیابی، فایل پایگاه‌داده را در مسیر `DB_PATH` قرار دهید.

## ساختار پروژه

- `src/main.js` — صحنه Three.js، کنترل‌ها، رابط کاربری، ارتباط زنده
- `src/style.css` — طراحی واکنش‌گرا و رابط موبایل
- `server/index.js` — API، احراز هویت، محدودیت دو حساب، WebSocket و منطق authoritative
- `public/manifest.webmanifest` — مشخصات PWA
- `public/sw.js` — service worker و cache پوسته
- `public/icons/` — آیکون‌های نصب
- `dist/` — خروجی تولیدی Vite (پس از build ساخته می‌شود)

## وضعیت قابلیت‌ها و محدودیت‌ها

نسخه حاضر یک پایه قابل‌بازی است: ثبت‌نام/ورود با هش گذرواژه، سقف دو حساب، دو جزیره، حرکت و نمایش بازیکن آنلاین، جمع‌آوری چهار منبع، شش نوع ساختمان، چت زنده و ذخیره جهان در SQLite پیاده شده‌اند. این نسخه هنوز سیستم کامل کشتی‌رانی، ماهی‌گیری تعاملی، کشاورزی زمان‌دار، جمعیت شبیه‌سازی‌شده، تجارت/دیپلماسی، نبرد، آب‌وهوای پویا، صدای نهایی و صحنه‌های داخلی را ندارد. این موارد نباید به‌عنوان قابلیت تکمیل‌شده تلقی شوند.

## عیب‌یابی

- اگر حساب دوم نمی‌تواند وارد شود، مطمئن شوید هر دو دستگاه به یک دامنه و سرور وصل‌اند.
- اگر بعد از restart پیشرفت پاک شده، مسیر `DB_PATH` روی دیسک پایدار تنظیم نشده است.
- اگر نصب PWA نمایش داده نمی‌شود، سایت را با HTTPS باز کنید و service worker را از DevTools بررسی کنید.
- اگر بازی اجرا نمی‌شود، Node.js 22+ را بررسی و سپس `npm install` را دوباره اجرا کنید.
